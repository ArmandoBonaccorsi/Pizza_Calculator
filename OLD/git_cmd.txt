🔄 Aggiornare la tua app su Streamlit Cloud

Collegamento a GitHub

Streamlit Cloud prende il codice direttamente da un repository GitHub.

Ogni volta che fai push di modifiche sul repository, Streamlit rileva l’aggiornamento e ricostruisce automaticamente l’app.

Flusso tipico di aggiornamento

Modifichi localmente app.py (o altri file).

Apri il prompt dei comandi nella cartella del progetto:

git add .
git commit -m "Descrizione modifica"
git push origin main


Streamlit Cloud ricostruisce l’app con la nuova versione.

Tutti gli utenti che aprono il link vedranno subito la versione aggiornata.

💡 In pratica: una volta collegato GitHub, ogni aggiornamento si pubblica automaticamente con un push.

Se vuoi, possiamo procedere step by step per:

Creare un account GitHub (gratuito)

Caricare la tua app (app.py, requirements.txt) su GitHub

Collegare GitHub a Streamlit Cloud e pubblicare la tua app
